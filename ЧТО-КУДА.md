# Что куда класть

Структура архива повторяет структуру репозитория. Распакуйте в корень проекта
и подтвердите замену — все пути совпадут сами.

```
app/globals.css      заменить
app/page.tsx         заменить
lib/typo.ts          новый файл
public/brand/        новая папка
public/fonts/        новая папка
public/images/       заменить содержимое
public/social/       заменить содержимое
```

## Что не трогать

`app/layout.tsx`, `next.config.ts`, `package.json` и остальные конфиги
остаются как есть.

## Один момент со шрифтом

В `globals.css` в самом начале лежит блок `@font-face` с Druk Wide и
переменная `--font-druk-wide` в `:root`.

Если в `layout.tsx` шрифт уже подключён через `next/font/local` — а судя по
сборке, это так, — переменная оттуда перекроет мою, и файлы из
`public/fonts/` просто не будут загружаться. Ничего не сломается.

Если хотите обойтись без дублирования, выберите одно:

- оставить `next/font` — тогда удалите блок `@font-face` и строку
  `--font-druk-wide` из `globals.css`, а папку `public/fonts/` можно не
  коммитить;
- перейти на `@font-face` — тогда уберите подключение шрифта из
  `layout.tsx`.

## Старые файлы картинок

В `public/images/` часть снимков раньше лежала в jpg и png. Я пережал всё в
webp, имена изменились на `.webp`. Старые файлы можно удалить — в разметке на
них больше нет ссылок:

```
agent-boat-selfie.png
agent-forest.jpg
agent-heic.jpg
agent-boat-pink.jpg
marzipan.png
```

Общий вес картинок: было около 26 МБ, стало 3,4 МБ.

## Проверка после сборки

```bash
npm run lint
npm run build
```

Готовые файлы появятся в `out`. Локально посмотреть — `npm run dev`.
