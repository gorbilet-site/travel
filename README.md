# Горбилет Travel

Адаптивный промосайт с городами, подборкой путешествий, фотографиями команды и ссылками на социальные сети. В первую очередь интерфейс рассчитан на мобильный трафик из Instagram, но имеет полноценную широкую версию для компьютеров.

## Локальный запуск

Понадобится Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Проверка статической сборки:

```bash
npm run build
```

Готовые файлы появятся в папке `out`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` автоматически собирает и публикует сайт после push в ветку `main` или `master`.

1. Создайте репозиторий на GitHub и отправьте в него проект.
2. Откройте `Settings → Pages`.
3. В поле `Source` выберите `GitHub Actions`.
4. Сделайте push в `main` или `master` либо запустите workflow вручную.

Workflow сам определяет имя репозитория и настраивает пути ресурсов для адреса вида `https://username.github.io/repository/`.
